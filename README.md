# Sector rotation map vs SPY

Sector rotation map vs SPY, auto-generated, educational, not financial advice.

- Live page: https://jgonthego.github.io/sector-rotation/
- `index.html` – interactive RRG-style chart (Plotly, loaded from cdn.plot.ly) + sortable table
- `rrg_weekly.png`, `rrg_daily.png` – static snapshots

Data: Yahoo Finance (public market data). JdK-style approximation; values won't match StockCharts' proprietary RRG exactly.

## How it updates
Pushes to `main` run `.github/workflows/publish.yml`, which decodes any `*.png.b64` snapshots into PNGs and mirrors `main` to `gh-pages` (the branch GitHub Pages serves). The page is regenerated by `update.py` + `make_web.py` in the generator workspace.
